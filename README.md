# 股票期貨最低保證金查詢 — v1

## 這是什麼

輸入股票代號或名稱,顯示目前每檔股票期貨(含小型)的**原始保證金金額**(買一口最少要準備多少錢),資料來自期交所「政府資料開放平台」官方端點,不是爬一般網頁,理論上不會卡防爬蟲。

## 檔案

- `fetch_margin_data.py` — 抓資料 + 計算,輸出 `margin.json`
- `index.html` — 查詢介面,讀 `margin.json` 顯示結果
- `margin.json` — 資料檔,**目前放的是兩筆假資料**(只是讓你先看畫面長怎樣),執行 `fetch_margin_data.py` 後會被真資料覆蓋

## 怎麼跑(第一次)

```bash
cd taifex_margin_app
python3 fetch_margin_data.py
```

跑完會在同一資料夾產生 `margin.json`。接著直接用瀏覽器打開 `index.html`,
或起個簡易伺服器(建議,避免部分瀏覽器擋本機檔案 fetch):

```bash
python3 -m http.server 8000
```

再開 `http://localhost:8000/`。

## ⚠️ 目前的限制,請先知道

1. **我(Claude)這邊的沙盒環境連不到 taifex.com.tw**(對外網域有白名單擋掉),
   所以這版程式碼**沒有實際跑過一次拿到真資料**來驗證欄位名稱、編碼是否完全對。
   我是靠官方頁面上看到的欄位結構(保證金比例表)+ 期交所開放資料一貫的命名規則寫的,
   每日行情那份欄位是用關鍵字模糊比對,盡量不會因為欄名小差異就整個壞掉。

   **麻煩你在自己電腦跑一次**,把終端機印出的:
   - `偵測到的欄位: [...]`
   - 最後「共 X 檔股票期貨,其中 Y 檔有算出金額」

   回報給我,如果 Y 是 0 或很少,代表每日行情那份欄位比對沒抓對,我再照實際欄名調整,一次就能修好。

2. **金額是估算值**,取整方式(無條件進位到元)不一定跟期交所官方公告完全一致,
   正式交易請以期貨商/期交所公告的保證金為準,不要直接拿這個下單。

3. 保證金比例表更新頻率低,但沒有寫自動比對「更新日期」欄位是否變動,
   v1 先做到「每次執行都重抓」,之後可以加上這個優化。

## 之後如果要做成每天自動更新的網站

- 用 GitHub Actions 排程(免費)跑 `fetch_margin_data.py`,把新的 `margin.json` commit 回 repo
- 用 GitHub Pages 或 Cloudflare Pages(免費)託管 `index.html`
- 這樣就是一個完全免費、每天自動更新的股票期貨保證金查詢網站
